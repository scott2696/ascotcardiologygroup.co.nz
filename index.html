Mysteries to solve together, bluffing games, and loud ones for when the night gets going. Every game has step-by-step instructions, and most only need one phone.

Choose a game

How it works

  1. Choose a game that suits the size of your group. Each card below shows how many players it needs.
  2. Read the "How to play" steps out loud. Every game page starts with them, plus an example.
  3. Play on the page. Most games run on one phone you pass around. A few need everyone's phone or a deck of cards.
