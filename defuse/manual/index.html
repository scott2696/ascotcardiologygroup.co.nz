Bomb Manual

  1. Ask the Defuser which parts the bomb has, and for the serial number. Several rules depend on its last digit (odd or even) and whether it contains a vowel (A, E, I, O, U).
  2. Find the matching section below and read the rules in order. Use the first rule that fits and ignore the rest.
  3. Tell the Defuser exactly what to do. A mistake costs a strike and 30 seconds.

Wires

3 to 6 coloured wires. Cut exactly one. Count wires from the top. Colours: red blue yellow white black

3 wires

  1. If there are no red wires, cut the second wire.
  2. If the first wire is black, cut the third wire.
  3. Otherwise, cut the first red wire.

4 wires

  1. If there is more than one yellow wire, cut the last yellow wire.
  2. If the serial number ends in an odd digit, cut the first wire.
  3. If there are no white wires, cut the fourth wire.
  4. Otherwise, cut the second wire.

5 wires

  1. If the last wire is black and the serial ends in an even digit, cut the fourth wire.
  2. If there is exactly one red wire and more than one yellow wire, cut the first wire.
  3. If there are no blue wires, cut the second wire.
  4. Otherwise, cut the first blue wire.

6 wires

  1. If there are no yellow wires and the serial ends in an odd digit, cut the third wire.
  2. If there is exactly one yellow wire and more than one white wire, cut the fourth wire.
  3. If there are no red wires, cut the last wire.
  4. Otherwise, cut the fourth wire.

The Button

A big coloured button with one word on it. You either tap it (press and let go quickly) or hold it.

  1. If the button is red and says HOLD, tap it.
  2. If it says DETONATE and the serial number contains a vowel, tap it.
  3. If the button is white, hold it.
  4. If the button is blue and says ABORT, hold it.
  5. If it says PRESS and the serial ends in an even digit, tap it.
  6. Otherwise, hold it.

Password

Five letter wheels. Each wheel can show 5 different letters. Only one word below can be spelled. Ask the Defuser to read out every letter each wheel can show, then rule words out. When you've found it, they set the wheels and press Submit.
